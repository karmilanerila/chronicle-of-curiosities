A cozy detective / art-restoration spot-the-difference game, built for the
[make.fun bounty](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451).

Five hand-painted procedural scenes — the Clockmaker's Midnight Workshop,
Botanical Conservatory at Dusk, Harbor Café & Lighthouse, Grand Observatory
Library, and Lantern Night Market — each with 7 differences to find between
two near-identical pictures side by side. Synchronized magnifying loupe,
gold markers, hint system, timer, strikes, combo scoring and synthesised
Web Audio chimes. 100% offline: all art is procedural Canvas 2D, all sound
is synthesised, zero network requests.

Play locally: `node serve.ts`, then open http://localhost:8080
